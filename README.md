## Network Configuration Engine

`network-config-engine` is a personal project for learning and applying programming techniques to network automation.

The project uses a fictional network environment of my own design to explore concepts such as structured data, validation, routing policy, and configuration generation. The goal is to build the project incrementally, adding capabilities as new automation use cases are developed.

## Current Capabilities

* Load site metadata from YAML
* Load device inventory from CSV
* Normalize inventory data
* Validate devices against known sites and zones
* Detect duplicate hostnames and IP addresses

## Project Goals

Over time, the project will grow into a general network configuration engine capable of modeling network infrastructure, validating source data, applying network policy, and generating standardized configuration.

## Project Data

All organizations, sites, devices, addressing, topology, and policy data used in this repository are fictional. This project is independently developed and does not contain employer or client source code, configurations, credentials, or proprietary data.
